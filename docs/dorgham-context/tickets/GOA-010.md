## Summary

Build the skeleton of the data ingestion pipeline. Implements a configurable scraper with pluggable source adapters and the text chunking + embedding pipeline.

No real data sources yet — uses a test fixture.

---

## Acceptance Criteria

- Python Lambda-compatible handler in `/services/ingestion/handler.py`
- `SourceAdapter` abstract base class with `scrape(url) -> list[Document]` interface
- `TestFixtureAdapter` returns 10 hardcoded sample documents for local development
- Chunking using `RecursiveCharacterTextSplitter`
  - `chunk_size = 500`
  - `overlap = 50`
- Embedding using `text-embedding-3-small` via OpenAI SDK
- Upsert to RAG service pgvector database through the RAG service internal API
- Idempotent document detection using `hash(source_url + content[:100])`
- DryRun mode logs what would be upserted without writing

---

## Implementation Notes

- Python with LangChain document loaders for chunking
- Abstract `SourceAdapter` pattern
- Embedding requests batched in groups of 100
- Upsert via `POST /internal/documents` on the RAG service

## Tests / Definition of Done

### Unit

- Chunker produces ≤500 token chunks with correct overlap
- Duplicate detection skips already ingested documents

### Integration

- Dry-run: fixture adapter processes 10 documents and logs 10 "would-upsert" messages
- Ingest same document twice and verify second run skips embedding API call (idempotency check via mock counter)
