## Summary

Connect them to the ingestion pipeline.

Run the first real ingestion and verify RAG quality.

---

## Acceptance Criteria

### Adapters

- IELTSOrgAdapter
- MastersPortalAdapter
- DAADAdapter
- CheveningAdapter

Each adapter implements:

```python
SourceAdapter.scrape() -> list[Document]
```

Metadata:

- source
- category
- country
- last_updated

### Ingestion

- First ingestion produces more than 200 documents in the vector database
- RAG quality check with 10 manually evaluated questions
- Respect robots.txt
- Add 1–2 second delay between requests

### Logging & Monitoring

Structured completion log:

```json
{
  "docs_processed": "...",
  "docs_skipped": "...",
  "docs_failed": "...",
  "embedding_tokens_used": "...",
  "duration_s": "..."
}
```

Published to S3 as a JSON report.

Metrics:

- `goa_ingestion_docs_processed_total`
- `goa_ingestion_embedding_tokens_total`
- `goa_ingestion_run_duration_seconds`

CloudWatch alarm:

- Failure rate greater than 10%
- Sends SNS email notification

## Implementation Notes

- Playwright for JS-heavy websites (Mastersportal)
- requests + BeautifulSoup for static websites
- One adapter class per source
- Exponential backoff on HTTP errors
- Store raw HTML in S3 alongside processed documents

---

## Tests / Definition of Done

### Unit

- Every adapter returns correctly structured `Document` objects from fixture HTML
- Failed documents increment `goa_ingestion_docs_processed_total{outcome='fail'}`

### Integration

- Full ingestion completes successfully
- More than 200 documents inserted
- Completion report written to S3 with correct structure

### Quality Evaluation

- Manually verify that 10 test queries return relevant results
