## Summary

Add a `visa_requirements` structured table to `rag_db` capturing visa application rules as they apply specifically to Egyptian applicants.

The existing `documents` table stores visa content as unstructured chunks.

This ticket adds structured, queryable visa data, financial requirements with Egypt-specific banking context, and the ingestion adapters to populate both from embassy and visa centre sources.

---

## Context — why Egypt-specific

- APS certificate
- Campus France Egypt
- Military status certificate
- Blocked account (Sperrkonto)
- Proof of funds in EGP context
- VFS Global Egypt
- Thanaweya Amma recognition
- Egyptian Police Criminal Record Certificate

## Acceptance Criteria

### Database

Create new table:

```sql
visa_requirements
```

Includes:

- id
- country
- visa_type
- issuing_body
- source_url
- egyptian_specific
- requirements
- proof_of_funds
- processing_days_min
- processing_days_max
- notes
- last_scraped_at
- content_hash

Unique key:

```
(country, visa_type, issuing_body)
```

### proof_of_funds JSON Schema

Contains:

- amount_eur
- accepted_account_types
- blocked_account_providers
- minimum_balance_period_days
